Lakeview Motors · Facelook / 1차 프로토타입

공개 사이트 (GitHub Pages에 올릴 파일)
  index.html    메인 딜러십 페이지
  admin.html    방문자에게 공개되는 '가짜 관리자' 애니메이션 페이지
  dan.html      댄 개인 페이지
  westside.html 웨스트사이드 정비소 페이지
  styles.css    공통 스타일
  site.js       이동 및 애니메이션 코드
  data.js       업체명, 게시물, 댓글, 타이핑 내용 등의 데이터

내 전용 로컬 편집기
  local-editor.html (공개 사이트에는 업로드하지 말 것)

사용법
  1. 압축을 해제하고 index.html을 브라우저로 열면 데모를 볼 수 있습니다.
  2. 모든 링크는 같은 폴더 안의 HTML 파일로 연결됩니다.
  3. 문구는 data.js를 수정하거나 local-editor.html에서 변경할 수 있습니다.
  4. 로컬 편집기에서 'data.js 내보내기'를 눌러 내려받은 data.js를 기존 것과 교체합니다.
  5. 공개 사이트용 6개 파일(index/admin/dan/westside, styles, site, data)만 GitHub Pages 저장소에 올립니다.

주의
  - 업체 연락처, 댄의 상세 프로필, 게시물 내용 및 사진은 임시 샘플입니다.
  - 사진 5장은 실제 사진 대신 임시 아이콘을 표시합니다.
  - 이 사이트는 실제 Facebook의 공식 사이트가 아닌 팬 창작용 패러디 시안입니다.
  - 별도의 실시간 서버, 회원 데이터, 실제 SNS 댓글 기능은 없습니다.
